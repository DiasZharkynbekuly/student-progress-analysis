# Student Progress Analysis

Python project that analyzes weekly test results of 200 students over 12 weeks to find
students with strong progress (to reward) and students with no progress (who need support).

> **Note:** the dataset is **synthetic** (generated by `generate_data.py`). The project is inspired by
> my work as a data analyst at a learning center, where I analyzed weekly student test results.

## What it does
- Calculates each student's weekly progress (linear trend of test scores)
- Compares the average score of the first 3 weeks with the last 3 weeks
- Splits students into 3 categories: high progress, steady progress, no progress
- Compares groups and shows the class average over time

## Results
| Category | Students |
|---|---|
| High progress (reward) | 47 |
| Steady progress | 62 |
| No progress (needs support) | 91 |
